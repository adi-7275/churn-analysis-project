# 📊 Churn Analysis and Customer Intelligence

## 📌 About the Project

This project analyzes customer churn to understand customer retention, subscription patterns, and factors influencing customer cancellations using Python, SQL, and data visualization.

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy)
* SQL (SQLite)
* Matplotlib & Seaborn
* Jupyter Notebook
* Excel

## 🔍 Key Analysis

* Data cleaning and preprocessing
* Customer churn and retention rates
* Churn analysis by subscription plan and state
* Average Revenue Per User (ARPU)
* Customer tenure and revenue at risk
* Customer complaints and escalation analysis
* Churn risk categorization
* Data visualization and correlation analysis

## 📈 Key Insights

* **Churn Rate:** 28.57%
* **Retention Rate:** 71.43%
* **Highest Churn:** Basic plan (60%)
* **Average Revenue Per User:** 18.85
* **Escalation Rate:** 19.05%
* **Escalation vs. Churn Correlation:** 0.77

## 📂 Project Files

* `churn_analysis.ipynb` – Complete analysis and visualizations.
* `customer_churn.db` – SQLite customer database.
* `customer_churn_data_raw.xlsx` – Raw customer dataset.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/adi-7275/churn-analysis-project.git
   ```
2. Install the required libraries:

   ```bash
   pip install numpy pandas matplotlib seaborn openpyxl sqlite-utils jupyter
   ```
3. Open Jupyter Notebook:

   ```bash
   jupyter notebook churn_analysis.ipynb
   ```
