# Customer Churn Analysis 📊

## Project Overview

A data analytics project to analyze customer churn, identify patterns, and understand customer retention using Python and SQL.

## Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* SQL, SQLite
* Jupyter Notebook

## Project Workflow

1. Data Import
2. Data Cleaning
3. Feature Engineering
4. Exploratory Data Analysis
5. SQL Analysis
6. Data Visualization
7. Business Insights

## Key Results

* Churn Rate: 28.57%
* Retention Rate: 71.43%
* Highest Churn: Basic plan (60%)
* Average Monthly Charges: 18.85

## How to Run

1. Install Python.
2. Install dependencies: `pip install -r requirements.txt`
3. Run `jupyter notebook`.
4. Open `churn_analysis.ipynb`.
5. Run cells from top to bottom.
